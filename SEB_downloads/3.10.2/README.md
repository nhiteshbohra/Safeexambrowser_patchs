# Safe Exam Browser 3.10.2

## How to install this version

### Step 1: Download the setup bundle from GitHub

Download the setup bundle of version 3.10.2 from GitHub:

[SEB_3.10.2.920_SetupBundle.exe](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/download/v3.10.2/SEB_3.10.2.920_SetupBundle.exe) (361.4 MB)

[GitHub release page for 3.10.2](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/tag/v3.10.2)

### Step 2: Install the setup bundle

Run the downloaded setup bundle on your computer and finish the installation.

### Step 3: Download the patch for your system

Come back to this GitHub page and download the patch that matches your system architecture, 64-bit (x64) or 32-bit (x86):

| Your system | Patch file | Size | SHA-256 |
|---|---|---|---|
| 64-bit (x64) | [SEB_3.10.2.920_x64_Setup.msi](SEB_3.10.2.920_x64_Setup.msi?raw=true) | 141.9 KB | `966c974173c238ec7715fd774276d9dba8c19de43e28da8ceed162c9550723e6` |

Not sure which one you need? Open **Settings > System > About** and look at **System type**.

### Step 4: Run the patch

Run the patch you downloaded and follow the prompts. When it finishes, Safe Exam Browser 3.10.2 is fully patched.
