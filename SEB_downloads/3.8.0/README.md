# Safe Exam Browser 3.8.0

## How to install this version

### Step 1: Download the setup bundle from GitHub

Download the setup bundle of version 3.8.0 from GitHub:

[SEB_3.8.0.742_SetupBundle.exe](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/download/v3.8.0/SEB_3.8.0.742_SetupBundle.exe) (299.8 MB)

[GitHub release page for 3.8.0](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/tag/v3.8.0)

### Step 2: Install the setup bundle

Run the downloaded setup bundle on your computer and finish the installation.

### Step 3: Download the patch for your system

Come back to this GitHub page and download the patch that matches your system architecture, 64-bit (x64) or 32-bit (x86):

| Your system | Patch file | Size | SHA-256 |
|---|---|---|---|
| 64-bit (x64) | [SEB_3.8.0.742_x64_Setup.msi](SEB_3.8.0.742_x64_Setup.msi) | 141.5 KB | `42c469c5d265b67708ba109b9d4745e17b247e96742839224bec7dc0c1a14dfe` |
| 32-bit (x86) | [SEB_3.8.0.742_x86_Setup.msi](SEB_3.8.0.742_x86_Setup.msi) | 141.8 KB | `ce22c9bb0e4d1ae3c6372de26ea819b0a536361af83753aef55a35cf64008a41` |

Not sure which one you need? Open **Settings > System > About** and look at **System type**.

### Step 4: Run the patch

Run the patch you downloaded and follow the prompts. When it finishes, Safe Exam Browser 3.8.0 is fully patched.
