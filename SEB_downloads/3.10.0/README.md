# Safe Exam Browser 3.10.0

## How to install this version

### Step 1: Download the setup bundle from GitHub

Download the setup bundle of version 3.10.0 from GitHub:

[SEB_3.10.0.826_SetupBundle.exe](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/download/v3.10.0/SEB_3.10.0.826_SetupBundle.exe) (333.1 MB)

[GitHub release page for 3.10.0](https://github.com/SafeExamBrowser/seb-win-refactoring/releases/tag/v3.10.0)

### Step 2: Install the setup bundle

Run the downloaded setup bundle on your computer and finish the installation.

### Step 3: Download the patch for your system

Come back to this GitHub page and download the patch that matches your system architecture, 64-bit (x64) or 32-bit (x86):

| Your system | Patch file | Size | SHA-256 |
|---|---|---|---|
| 64-bit (x64) | [SEB_3.10.0.826_x64_Setup.msi](SEB_3.10.0.826_x64_Setup.msi) | 142.3 KB | `0dae7baf4d5bb06c0beb33694835ac40620b5cdc42917583c650964e4ecdcbe8` |

Not sure which one you need? Open **Settings > System > About** and look at **System type**.

### Step 4: Run the patch

Run the patch you downloaded and follow the prompts. When it finishes, Safe Exam Browser 3.10.0 is fully patched.
